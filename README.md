# KURT - Künstliche Universelle Reaktions-Technologie

A local AI assistant for Windows 11. Control your system, get the news, have a conversation — running entirely on your machine, with more features coming soon.
The only supported language for now is german.

#installation
KURT requires two local dependencies: the Ollama phi3:mini model for AI and a Vosk vosk-model-de model of your choice for speech recognition.
If you want to use the todo features too you have to download my "todo list for KURT"
